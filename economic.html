Transparansi Data

Sumber & Metodologi

Sumber Data
  • Bank Indonesia (bi.go.id) — BI-Rate, Deposit/Lending Facility, jadwal RDG, cadangan devisa, kredit perbankan.
  • Badan Pusat Statistik / BPS (bps.go.id) — inflasi, PDB, ketenagakerjaan (Sakernas), neraca perdagangan.
  • World Bank Open Data API — indikator tahunan (pertumbuhan PDB, inflasi, pengangguran, current account) untuk perbandingan historis, diambil langsung saat halaman dibuka.
  • Frankfurter API (data ECB) — kurs referensi USD/IDR, diambil langsung saat halaman dibuka.
  • TradingView — widget harga pasar langsung untuk USD/IDR, IHSG, emas, dan kalender ekonomi global.
  • Trading Economics — data pelengkap untuk harga emas dan yield obligasi pemerintah 10 tahun.
Batasan yang Kami Sadari

BI, BPS, dan Bursa Efek Indonesia tidak menyediakan API publik gratis yang bisa diakses langsung dari browser (kena kebijakan CORS). Untuk indikator yang datanya perlu diperbarui manual (BI-Rate, inflasi, PDB, neraca dagang, cadangan devisa, kredit), kami menampilkan angka rilis resmi terakhir lengkap dengan tanggal dan sumber — bukan data yang mengalir otomatis setiap detik. Untuk integrasi data real-time penuh dari sumber resmi, dibutuhkan backend/proxy yang menjadwalkan pengambilan data dari BI/BPS, atau berlangganan vendor data (Refinitiv, Bloomberg, IBPA).
